# T-09 — DEV: game flow, node map, formation, combat HUD, camp/merchant/event/reward UI, debug hooks

**Role:** DEV · **Owned paths:** src/main.ts, src/game/** (new), src/ui/**, src/style.css, index.html, tests/unit/game*.test.ts
**Inputs:** CLAUDE.md, pm/STATE.md, src/sim/index.ts (Run, Battle APIs), src/sim/bots.ts (playBattleWithBot / bot policies), src/render/combatView.ts + src/render/* public APIs (read signatures, don't edit render internals — if you need a render hook, add it minimally and note it), src/data/index.ts, docs/content/GDD.md
Assets: assets/regions/**, assets/sprites/**, assets/heroes/*_portrait.jpg, assets/key_art.jpg (via the render assets registry).

## Goal
A full run is playable in the browser from a minimal start screen through 4 regions to win/loss, with real art.

## Deliverables
1. `src/game/app.ts` — a screen state machine driven by `Run.status`: map → (formation → battle → reward) | camp | merchant | event → … → won/lost. Owns the Three renderer loop (reuse existing render context), switches the diorama region per region, and swaps between "march" mode (caravan walking on the spot, layers scrolling = parallax) on the map screen and "battle" mode.
2. Node map screen (DOM overlay over the marching diorama, painted-parchment look via CSS until ui/map_bg art exists; use `assets/ui/map_bg.jpg` if present): shows current region's 3 steps + boss as connected nodes with icons per type (fight/elite/camp/merchant/event/boss), reachable nodes highlighted, click/tap to choose. Shows gold (Ember Shards), relics bar (hover/tap = description), party HP.
3. Formation screen: drag (pointer events — mouse AND touch) the 4 hero portraits into a 2×2 grid (front/back rows), with tooltip "Front row takes 70% of melee hits". Remembers last formation. "Fight" button.
4. Combat HUD: per-unit HP bar + ATB gauge bar + shield pips with weakness icons (Slash/Pierce/Fire/Holy — simple pixel SVG/CSS icons, revealed by default), Broken badge; floating damage numbers (crit/weak styled bigger), positioned via `combatView.unitScreenPos`. Big Ember meter + IGNITE button (pulses when full; Space key). Speed toggle 1×/2× (keys 1/2). Esc = pause overlay (resume / quit run). Battle loop: `battle.tick(dt * speed * combatView.timeScale)` (fixed 0.05 step accumulator), feed events to combatView and HUD.
5. Reward screen after fights: gold gained, relic choice (elites/bosses: pick 1 of 3), level-up note after region bosses.
6. Camp (heal 40% vs +1 skill rank for a chosen hero), Merchant (stock list, buy, leave), Event (title, text, choices → outcome text) screens.
7. Minimal start screen (key art + "Begin" + seed shown small) and minimal won/lost screens with run stats — T-12 will polish these and add story scenes; leave clean hooks: `app.onStory(sceneId, done)` default = immediately done.
8. Debug hooks: `window.__debug = { seed, run, gotoNode(i), winFight(), setRelics([...ids]), runBot('greedy'|'random'|'ignite-never'), state() }` — winFight instantly wins the current battle; runBot auto-plays the rest of the run in the real UI at high speed (or headless + jump to end screen if simpler: implement an option `{headless:true}`).
9. UI styling: pixel font (already loaded), 9-slice-style panels in dark wood + brass via CSS border-image or layered borders/gradients (no art dependency), readable at 1280×720 and on mobile landscape 844×390 (scale UI with clamp()/vh units). Touch targets ≥ 40 px.

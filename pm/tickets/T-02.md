## Spec summary (authoritative)
- 4 regions: whisperpine (Whisperpine Woods), glass_dunes (Glass Dunes), frostspire (Frostspire Pass), solenne (Gates of Solenne). World darkens each region.
- Each region map: 3 steps of choice (2–3 nodes per step) then a boss node. Region 4 boss = The Hollow King (3 phases). ~13 encounters per run total.
- Node types: fight, elite (harder, guaranteed relic), camp (heal 40% party HP OR +1 skill rank for one hero), merchant (buy relics/consumables with Ember Shards), event (text choice risk/reward; 6 unique events).
- Formation 2×2: front row takes 70% of melee hits; back row only ranged & AoE.
- ATB combat: gauge fills by SPD; acts when full. Damage types: slash, pierce, fire, holy. Enemies have shield points + 1–2 visible weaknesses. Weakness hit = −1 shield. 0 shield = Broken: skips next action, takes +50% dmg for 2 actions.
- Ember meter fills from hits & breaks; Ignite = all heroes cast ultimate.
- Heroes: Bram the Warden (tank, AI: taunt/guard lowest-HP ally), Lysa the Ranger (archer, pierce, shoots lowest-HP enemy or weakness match), Oren the Ember Priest (heals <50% else fire), Kit the Duelist (crit rogue slash, hits Broken enemy else highest-damage enemy). Each: basic attack, 1 skill (ranks 1–3), 1 ultimate. HP/ATK/SPD auto level after each region.
- Mira: driver/narrator NPC.
- 16 relics, passive, synergistic, with tags (e.g. "Break also burns", "Front row +20% DEF", "Ignite heals 15%").
- Enemies: 9 normal (3 per region for regions 1–3; region 4 reuses a mix), 3 elites (one per region 1–3; region 4 reuses), 3 region bosses + Hollow King. Distinct weakness patterns. Bosses: 2× size.
- Consumables for the merchant (3–4 kinds).

## Deliverables
1. `src/data/types.ts` — TypeScript types for everything below (exported interfaces). This is the contract the sim (src/sim) will import. Keep it pure TS (no imports). Include: DamageType, HeroDef, SkillDef (with per-rank values), UltimateDef, EnemyDef (id, name, region, tier normal|elite|boss|final, hp, atk, spd, def, shield, weaknesses, attack pattern: list of actions with type melee|ranged|aoe, damageType, power, optional status), BossPhase (hp threshold, new actions/weakness change, add shields), RelicDef (id, name, description, tags[], effect as a discriminated union of a SMALL fixed set of effect kinds with numeric params, e.g. {kind:'stat_mult', stat, row?, value}, {kind:'on_break', effect:'burn', value}, {kind:'on_ignite_heal', value}, {kind:'ember_gain_mult', value}, ... ~10–14 kinds), ConsumableDef, EventDef (id, title, text, choices[] each with outcomes: gold/hp/relic/curse/fight with probability), RegionDef (id, name, enemy pools for fight/elite, boss id, palette hint), MapGenConfig (steps per region, node count range, node type weights per step), BalanceConfig (ember meter gain per hit/break, break duration, break dmg mult 1.5, front row melee share 0.7, gauge scale, level-up growth per region, gold rewards, merchant prices, camp heal 0.4, hard mode multipliers).

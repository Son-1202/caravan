# T-06 — DEV: bots + scripts/balance.ts (headless balancing harness)

**Role:** DEV · **Owned paths:** src/sim/bots.ts (new), scripts/balance.ts, tests/unit/bots*.test.ts, docs/qa/balance_report.md, package.json (scripts only)
**Inputs:** CLAUDE.md, pm/STATE.md, src/sim/index.ts (+ run.ts/combat.ts APIs), pm/handoffs/T-04-data-issues.md, src/data/types.ts

## Deliverables
1. `src/sim/bots.ts` (pure, no node/DOM imports): `type BotName = 'random'|'greedy'|'ignite-never'`; `playRun(seed, bot, opts?) → RunResult` that drives a whole `Run` from start to won/lost, including all decisions: node choice, formation, relic picks, camp, merchant purchases, event choices, and Ignite timing inside battles (tick the battle with dt 0.05 and call ignite per bot policy).
   - random: random route/relics/formation/choices; Ignite as soon as the meter is full.
   - greedy: heuristics — Bram front row (+ the next-tankiest), prefers relics by tag synergy with relics already held, heals at camp when party HP < 60% else upgrades, buys the best affordable relic, picks the lowest-risk event option; holds Ignite until an enemy is Broken (or a boss is Broken / party is about to die).
   - ignite-never: like greedy but never Ignites.
   RunResult: won, regionReached, encounters, per-fight records {kind: normal|elite|boss|final, region, durationSec, won, ignites, breaks}, relics held, Hollow King phases reached, total time.
   Also export `playBattleWithBot` for reuse by window.__debug later.
2. `scripts/balance.ts` (tsx): runs N seeded runs per bot (default 5000; CLI `--runs N`, `--bot name`), using worker_threads or simply a fast loop (target: full 3×5000 in < 3 min; if too slow, report timings and default to what fits in 3 min, minimum 1000/bot). Computes all B7 metrics:
   | Metric | Target |
   | Win rate random | 20–35% |
   | Win rate greedy | 65–85% |
   | ignite-never | ≥ 15 points below greedy |
   | Any single relic | share among greedy WINS ≤ 1.5× its baseline share (baseline = share among all greedy runs' held relics) |
   | Avg normal fight | 15–35 s at 1× |
   | Avg boss fight (region bosses + Hollow King) | 45–90 s |
   | Hollow King | each of 3 phases triggers in > 90% of HK fights |
   Writes `docs/qa/balance_report.md` (table with value, target, PASS/FAIL, date, runs per bot, plus per-relic table and per-region win/death distribution) and prints a summary. Exit code 0 always.
3. `npm run balance` works. Test: bots are deterministic for a seed, and a greedy run terminates.

## Acceptance
build + test pass. Run the balance once and report the headline metrics (current data is known to be too easy — that's fine; tuning is T-10). Do NOT modify src/data.
## Out of scope
Tuning data. Rendering.

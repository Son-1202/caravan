# T-01 — DEV: Scaffold Vite+TS+Three, diorama renderer, post-FX, deploy-ready build

**Role:** DEV · **Owned paths:** package.json, package-lock.json, tsconfig*.json, vite.config.ts, vitest.config.ts, index.html, vercel.json, public/**, src/** EXCEPT src/data/**, tests/unit/**, README.md
**Inputs:** CLAUDE.md, pm/STATE.md

## Goal
A buildable, deployable skeleton that already shows the HD-2D diorama look with placeholder colored planes.

## Deliverables
1. `npm create`-style Vite + TS strict project (don't actually run interactive create; write files). Deps: three, postprocessing, howler, @fontsource/pixelify-sans, @fontsource/silkscreen. Dev: typescript, vite, vitest, tsx, @types/three, @types/howler, @types/node, sharp.
   Scripts: dev, build (`tsc --noEmit && vite build`), preview, test (`vitest run`), balance (`tsx scripts/balance.ts`), pixelize (`tsx scripts/pixelize.ts`).
2. `vercel.json` (framework vite, outputDirectory dist). Vite `base: './'`. Make Vite serve `assets/` (repo root, owned by ART) as static, e.g. via `publicDir` stays `public` + import assets with `import.meta.glob('/assets/**/*.png', { eager: true, query: '?url', import: 'default' })` in an `src/render/assets.ts` registry that returns a URL or `null` (so missing art falls back to placeholders gracefully).
3. `src/render/diorama.ts`: Region diorama = layered textured planes at Z: sky −30 (code gradient shader + drifting particles), far −15, mid −6, actors 0, fg +4. Each layer takes a texture URL or a placeholder flat color per region. Region config keyed by id: `whisperpine`, `glass_dunes`, `frostspire`, `solenne` (palettes in CLAUDE.md). Layers sized to cover the frustum at their depth.
4. Camera: PerspectiveCamera FOV 28, slight downward tilt, gentle idle sway. `setScroll(speed)` scrolls layers at different rates (parallax; textures with RepeatWrapping offset).
5. Lights: Ember lantern = warm PointLight with noise flicker (exported `EmberLight` class). Per-region cold DirectionalLight "dusk". Use MeshStandardMaterial or a simple lit material so lights read on planes.
6. Sprite billboard helper `src/render/sprite.ts`: plane with NearestFilter texture, alphaTest, blob shadow (radial-gradient plane), placeholder colored rectangle if no texture. Procedural idle breathing (scale y sine).
7. Post-FX `src/render/postfx.ts` using `postprocessing`: tilt-shift (TiltShiftEffect), bloom, vignette, noise (film grain), a color grade per region (BrightnessContrast/HueSaturation or LUT), ChromaticAberration with `pulseChromatic()` method. Quality toggle (High/Low) + auto-drop to Low if FPS < 45 for 3s.
8. `src/main.ts` boots a demo: renders the `whisperpine` diorama with 4 placeholder hero sprites on the left, 3 enemy placeholders on the right, the Ember lantern on a wagon placeholder, layers slowly scrolling. Press 1–4 to switch region (demo only). `window.__debug = {}` stub object.
9. Global CSS: pixel font loaded, body background #0b0a10, canvas full-viewport, responsive.
10. One trivial vitest test so `npm run test` passes.
11. README.md: title, short pitch, run/build/test commands, controls placeholder, "Live URL: TBD".

## Acceptance
- `npm install`, `npm run build` (zero TS errors), `npm run test` all pass.
- Playwright screenshots (1280x720) of the demo in 2 regions saved to docs/qa/screens/T-01-*.png — you may write a tiny script in scripts/ to do this (start `npx vite preview` or dev server in background, then kill it).
- Visible: depth blur at top/bottom (tilt-shift), bloom on the lantern, vignette, parallax motion.

## Out of scope
Combat logic, UI screens, real art, audio.

## Part A — pixelize pipeline
`scripts/pixelize.ts`: batch mode `npm run pixelize` processes every `assets/raw/{heroes,enemies,npc}/*_sprite.png` → `assets/sprites/<group>/<id>.png`: trim, downscale with a smoothing kernel to target height (heroes/normal enemies ~96 px, elites ~120, bosses ~192 — read tier from src/data/enemies.json; bosses and the final boss ~2× normal), alpha threshold (hard edges, strip magenta/halo fringe: any pixel with strong magenta tint → transparent or desaturated), palette quantize (~32 colors via sharp png palette), add a 1-px dark outline (#1a1020) around the opaque silhouette. Idempotent; skips missing groups. Run it now for heroes (and enemies if any exist yet).

## Part B — assets registry
Extend `src/render/assets.ts` glob to png+jpg+webp. Diorama uses `assets/regions/<id>/{far.jpg,mid.png,fg.png}` when present (correct aspect, cover the frustum, NearestFilter is NOT needed for painted layers — use Linear + mipmaps for backgrounds, Nearest for sprites).

## Part C — CombatView (`src/render/combatView.ts`)
```ts
export interface CombatViewOpts { regionId: string; }
export class CombatView {
  constructor(ctx: RenderContext /* whatever the existing scene/camera/postfx bundle is; export it */, opts: CombatViewOpts);
  setup(state: BattleState, formation: Formation): void; // spawn hero sprites (2x2 formation positions, front row closer to center) on the left, enemies on the right (bosses 2x), wagon+Ember behind heroes
  applyEvents(events: SimEvent[]): void;   // queue visual reactions
  update(dtReal: number): void;            // tweens, particles, lights
  dispose(): void;
  readonly busy: boolean;                  // true while a blocking cinematic (break slow-mo / ignite) plays
  timeScale: number;                       // the renderer's suggestion for sim speed (slow-mo on break = 0.3 for ~0.4 s)
}
```
Visual vocabulary (all procedural, no sprite-sheet animation): idle breathing; lunge toward the target on attack (melee) or a projectile streak (ranged: arrow line; fire: orange orb with a short-lived orange PointLight; holy: gold beam/flash with a gold PointLight); hit = recoil + white flash (shader uniform or material emissive) + small spark particles; heal = green-gold rising motes; death = dissolve into ash particles drifting up; Break = shatter particles (shield shards), short screen flash, chromatic-aberration pulse (postfx.pulseChromatic), timeScale slow-mo; Ignite = screen-wide warm flash, the Ember light flares, each hero does a quick jump+glow ultimate; boss phase = dark pulse + camera shake. Blob shadows under every unit; squash on landing after a lunge.
Also expose `unitScreenPos(uid): {x,y} | null` (projected to CSS px) so the DOM UI can place HP bars, shield pips and damage numbers.

# T-14 — QA: Playwright end-to-end tests, screenshot review, bug tickets

**Role:** QA · **Owned paths:** tests/e2e/**, docs/qa/** (read-only elsewhere), package.json (add an `e2e` script only)
**Inputs:** CLAUDE.md, pm/STATE.md, README.md, src/game/** (read; find window.__debug and its API), scripts/screens-*.ts (examples of driving the game)

## Deliverables
1. `tests/e2e/game.e2e.ts` (plain node + playwright `require('playwright')`, run via tsx; NOT vitest), run by `npm run e2e`: builds are assumed to exist (`npm run build` first); serve `dist/` with `npx vite preview --port 4173` started and killed by the script. Checks:
   (a) the game loads with zero console errors / page errors (collect `console` type error + `pageerror`);
   (b) runs `__debug.runBot('greedy')` through a full run via the debug hooks (with several seeds if one loses — try up to 5 seeds until one wins, and record the outcomes) and reaches the win or lose screen without errors;
   (c) screenshots (1280×720, deviceScaleFactor 1) → docs/qa/screens/final/: title, map, combat in each of the 4 regions (use gotoNode/region jumping or the bot paused at the right point — find a way; a debug hook for jumping to a region is fine to request via a bug ticket if missing), a Break moment, the Hollow King boss fight, the twist dialogue, and the win screen. Also mobile 844×390: map and battle.
   Print a pass/fail summary; exit non-zero on failure.
2. Review every screenshot yourself (open the images). Write docs/qa/QA_REPORT.md: the checklist of the Definition of Done items you can verify (4 regions, 13 encounters, 16 relics, all enemies/bosses, 5 story scenes, twist, HD-2D look, mobile), the results, and a list of bugs found, each with severity (blocker/major/minor), repro steps and the screenshot path.
3. For every blocker/major bug, write a ticket file pm/tickets/T-15-<n>.md (role DEV, owned paths, goal, acceptance). Do not fix code yourself.

## Acceptance
`npm run e2e` runs; QA_REPORT.md exists; final screenshots exist. Report ≤ 150 words: pass/fail, bug count by severity, list of T-15 tickets.
